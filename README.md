# 🚀 Personal Portfolio Website

A modern, responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, and education as a Software Engineer.
---

## 📌 Features

- Modern UI with gradient dark theme  
- Fully responsive design (mobile + desktop)  
- Profile section with animated border  
- Typing animation (dynamic roles)  
- Interactive hover effects  
- Projects showcase with GitHub links  
- Skills & tools section  
- Education section  
- Contact form with social links  
- Animated particle background  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Font Awesome
